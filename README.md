# D2倖存者工具包

《D2 Survivors》桌面版的非官方繁體中文獨立工具包（Windows Electron 桌面應用），整合存檔修改器、遊戲輔助器、存檔合規檢查與繁體中文化。物品直接使用遊戲本身的產生器製作，數值範圍與遊戲一致。

- **Windows 桌面版**：到 [Releases](https://github.com/nojackno2-ctrl.github.io/d2-survivors-toolkit) 或 GitHub Releases 下載獨立桌面應用（免安裝可攜版；開發重構中，以 `editor/` 為主體）。

> ⚠️ 修改前請先備份存檔。本工具與遊戲官方無關，使用風險自負。

## 獨立桌面版架構

官方網頁版（`d2survivors.lol/play/`）已停用，本工具包僅針對 Windows 桌面版《D2 Survivors》運作：

- **輔助器（開發中）**：由獨立桌面應用啟動／連接遊戲，透過 Chrome DevTools Protocol（CDP）唯讀讀取遊戲狀態，並以模擬鍵盤／指標輸入操作遊戲，預設不在遊戲內常駐掛接官方函式。
- **存檔修改器**：直接讀寫電腦本機的遊戲存檔（LevelDB `Local Storage` 與 `save/save.json` 雙寫並重新簽章）；寫入前須關閉遊戲並自動建立備份。
- **繁體中文化（開發中）**：以替換遊戲 `resources/app.asar` 內的語言資料檔（`ko-*.js`）並設定遊戲語言為 `ko` 完成，支援一鍵還原原版；安裝於系統目錄時需系統管理員權限，遊戲更新後須重新套用。
- **排行榜上傳一律封鎖（開發中）**：定位為單機爽玩。透過工具包啟動遊戲時，將官方環境變數 `D2S_LEADERBOARD_URL` 與 `D2S_REPORT_URL` 指向本機空伺服器以丟棄上傳請求；寫入存檔時強制 `leaderboard.off = true`。

## 修改器功能

| 頁面 | 說明 |
|---|---|
| 物品 | 瀏覽角色、傭兵、倉庫、背包、護身符欄的物品；編輯底材、品質、屬性，複製或移動物品；顯示每個屬性的遊戲範圍 |
| 製作裝備 | 自選底材、品質與屬性訂製裝備；魔法／稀有分成「前綴」「後綴」「固有屬性」三區，選好底材與品質就顯示各區已用／上限；列出底材可用的詞綴範圍，新增屬性預設最大值；名稱依遊戲詞綴規則決定 |
| 裝備庫 | 從遊戲全部獨特、套裝、符文之語中挑選製作，可一次製作多件、取最高數值（獨特、套裝、符文之語需解除修改限制） |
| 帳號 / 強化 | 金幣、光之碎片、傭兵欄；恰西永久強化與額外強化（未解除限制時單次升級花費不超過 100 億）；各角色技能修改、重置次數、恐怖區域 |
| 反修改偵測 | 合規檢查：依遊戲本身的規則（金幣上限、物品合法性、稀有物品 +技能、屬性點上限、角色等級、簽章、匯入痕跡等）掃描存檔，標出會被排行榜拒絕的項目 |
| 存檔管理 | 快照備份、還原、建立全新存檔 |
| 原始 JSON | 直接檢視與編輯存檔內容 |
| 設定 | 「解除修改限制」：預設關閉，依原版規則限制數值與裝備屬性 |

未解除修改限制時，修改器依原版規則限制可製作內容：不能製作獨特、套裝、符文之語；魔法最多 1 前綴＋1 後綴，稀有 2～6 個詞綴（前後綴各最多 3 個、稀有珠寶最多 4 個、同類不重複，依 Diablo II 原版規則）；稀有物品最多一條職業／技能樹 +技能（遊戲 10/20 起的規則）；屬性點不超過等級應得上限；屬性下拉選單只列出依規則還能加入的屬性；金幣不超過 100 億；恰西升級單次花費不超過 100 億。這些限制不代表排行榜會接受成績。

> ⚠️ **單機模式：排行榜上傳強制關閉。** 工具包定位為單機爽玩：寫入存檔一律強制 `leaderboard.off = true`，並於從工具包啟動遊戲時封鎖排行榜上傳。

開啟「解除修改限制」就是單機爽玩模式：製作裝備不設任何限制（任何屬性、任何數量、超過原版數值、所有品質），讓玩家盡情製作超強裝備。

屬性範圍來自統一的資料庫：獨特、套裝、符文之語取遊戲產生器的上下限；魔法、稀有等其他品質取底材可用詞綴的範圍。

## 遊戲中文化

只提供繁體中文，**譯名以原版《暗黑破壞神 II》官方繁中為準**（裝備、屬性、技能、怪物、地名等），字典 `lang/zh-TW.json` 由本機安裝的《暗黑破壞神 II：獄火重生》字串表核對產生。

- **資料檔替換（開發中）**：將遊戲 `resources/app.asar` 內的韓文語言資料檔（`ko-*.js`）值替換為繁體中文，並可一鍵還原回原版 `app.asar`；目前 `lang/tools/desktop-lang.mjs` 正在改寫為支援 `--apply`／`--restore`／`--status` 的資料檔替換流程。
- **物品名稱**：依原版繁中格式——魔法物品「字尾＋字首＋底材」、稀有名稱「字首＋字尾」、怪物稱號與名稱直接相接。字典使用 `item:`／`affix:`／`monster:`／`unique:` 前綴區分同英文不同譯名（例如 Spirit：符文之語「精神」、魔法字尾「魂靈之」）。
- **以官方資料更新字典**（需本機安裝 D2R）：
  1. `node lang/tools/d2r-strings.mjs`：讀取 D2R 的 CASC 資料（只讀不改），匯出官方字串與 excel 表到 `backups/d2r-strings/`（Git 忽略，不放官方資料進倉庫）。
  2. `node lang/tools/d2r-align.mjs`：列出字典名稱類詞條與官方的差異；加 `--write` 寫回。
- **遊戲更新後補字**：執行 `node lang/tools/lang-missing.mjs zh-TW 缺漏.json` 列出翻不到的英文，翻好後補進 `zh-TW.json`。

## 遊戲輔助器

輔助器專注於只讀取遊戲記憶體狀態並以模擬輸入操作遊戲（預設不修改存檔與官方函式；特定功能如無敵／停止關卡時間、經驗倍率／虛擬淬鍊精華、升級選卡重抽預判、雇傭兵雇用／營地整備於對應開關開啟時才啟用，關閉即還原，目前正進行桌面 CDP 架構整合，開發中）。

| 分頁 | 功能 |
|---|---|
| 戰鬥輔助 | 自動喝水（含預判致命傷害，靠近魔王時提早補血）；自動走位：偵測地圖上的怪物、看小怪合計威脅（打不痛、能秒殺的不閃）、預判包圍提前往空隙走、重擊飛彈與精英近戰左右橫移閃避、依技能攻擊距離決定站位；自動撿裝（全圖撿取，沒用的賣掉、有用的穿上或存倉庫）、全圖吸經驗；死亡保護（快被打死時以原版「儲存並離開」回營地，再自動繼續） |
| 自動戰鬥 | 三種自動模式（見下）；升級一定選卡（依排行榜高手配法，技能進化後可再次習得基礎技能）；屬性點依排行榜比例分配；換裝讓每個欄位都有裝備、優先排行榜推薦的獨特／套裝；咒符依屬性挑選；讀法典並套用技能變體；使用任務獎品；回營地先交任務再整備（收藏、存倉庫、賣裝、買生命藥水、恰西升級與買裝備）；技能配置和排行榜差太多時向阿卡拉付費重置技能 |

**自動模式**

| 模式 | 內容 |
|---|---|
| 任務模式 | 完成所有任務並推進難度：檢測目前任務狀態（例如「尋找凱恩」進行到哪一步），撿到卷軸回營地請阿卡拉翻譯、觸碰石塊陣、進傳送門救出凱恩，回營地向阿卡拉／凱恩交任務；打完巴爾先回營地整備再開最高難度；75 級以上不回普通、85 級以上不回惡夢刷。三難度任務完成後，可依設定自動切換天梯或固定關卡 |
| 固定關卡模式 | 重複刷指定難度（普通／惡夢／地獄） |
| 天梯模式 | 推關（恐怖層數往上推）或固定層數（重刷指定層，須已通關） |

- 「自動戰鬥」開著就包含戰鬥輔助（走位、閃避、喝水、撿物）；只開「戰鬥輔助」則只幫忙戰鬥、不自動推進。
- 遊戲版本更新後，設定上方會提示「遊戲已更新」，代表尚未驗證新版，部分功能可能失效。
- 不保證存活或通關；遊戲機制分析見 [docs/game-analysis](docs/game-analysis/README.md)。

**實測數據**

- 全新存檔的法師全自動打通普通（第五幕 82 級擊敗巴爾）與惡夢，推進到地獄第二幕；在地獄陣亡後自動回惡夢練等。
- 以 35 個存檔長時間實戰，依結果修正精英判斷、閃避、換裝、配點、交任務等數十項行為；營地整備實測可自動賣裝、買穿皮甲並升級生命。
- 選卡、配點、技能變體與換裝參考排行榜各職業前 50 位玩家的實際配置。

**自動戰鬥並不完美**

- 不保證存活或通關：實測曾在惡夢撿物時被頭目一擊打掉 900 血、藥水用完時走進毒魔群陣亡；地獄難度仍常陣亡。
- 最高難度連續失敗 3 次會自動回低一級刷，進度可能比手動慢。
- 讀法典、使用任務獎品、交伊尼弗斯卷軸、石陣鑰匙等流程尚未完整實測，可能需要手動處理。
- 建議偶爾查看狀況，長時間無人看管前請先備份存檔。

## 桌面版使用方式

1. 下載桌面版可攜式執行檔（或從 `editor/` 建置），執行前可對照 `SHA256SUMS.txt` 確認檔案完整。
2. 關閉遊戲後開啟修改器，直接讀寫本機已安裝遊戲的存檔；修改後按「寫入存檔」，每次寫入前會自動備份。
3. （開發中）透過工具包啟動桌面版遊戲，可使用輔助器與中文化功能，並確保排行榜上傳封鎖生效。

執行檔未經程式碼簽署，Windows 可能跳出 SmartScreen 警告，請選「其他資訊 → 仍要執行」。

## 注意事項

- 修改套裝、魔法、稀有物品的屬性後，遊戲可能判定為「Not legit」（只影響排行榜），可到「反修改偵測」頁處理。
- 自訂任意屬性不一定有對應的遊戲名稱；無法唯一判定名稱時會提示，不會猜測。
- 「可用詞綴範圍」是此底材可能出現的詞綴，並非都能同時出現。
- 遊戲更新後部分功能可能失效，請回報問題；每次遊戲更新，本專案全部功能都會重新驗證。
- 「診斷資訊」會記錄物品引擎各步驟耗時與遊戲版本，回報載入慢或異常時請附上。

## 開發

```bash
cd editor
npm install
npm start          # 執行桌面版（開發用）
npm run dist       # 封裝 Windows 可攜版
```

| 位置 | 內容 |
|---|---|
| `helper/tests/autobot.cjs` | 輔助器模擬測試（Electron 執行，失敗不中斷，最後列出全部失敗項目） |
| `tests/live-harness/` | 實機測試框架（正改寫為啟動桌面版 exe 進行隔離測試，開發中） |
| `helper/tools/ladder-learn.js` | 排行榜學習：各職業前 50 位不同玩家，同一玩家只取最高恐懼層紀錄 |
| `docs/game-analysis/` | 遊戲反編譯分析（核心、戰鬥與命中率、物品與掉落、成長與任務、介面、全職業技能），不含遊戲原始碼 |
| `AI_HANDOFF.md` | 交接紀錄、長期規則與所有 AI 代理文件（單一檔案） |

### 專案資料夾結構

| 位置 | 內容 |
|---|---|
| `editor/` | 獨立桌面應用（Electron）：`main.js`、`core.js`（本機存檔讀寫）、`engine.js`（物品引擎）與版號 `package.json` |
| `helper/` | 輔助器：`autobot.js`、設計文件、排行榜學習工具、模擬測試 |
| `lang/` | 語言：字典 `zh-TW.json`、官方字串匯出與核對、補字與桌面資料檔注入工具（`lang/tools/`）、測試 |
| `modifier/` | 存檔修改器：`editor.html`、`engine-page.js`、`patch.mjs`、`signatures.json`、`gamedata.json`、`i18n.js`、`zh.js`、測試 |
| `guard/` | 存檔檢查與防護：`save-check.js`、`guard.html`、測試 |
| `verify/` | 遊戲快照比對與回歸驗證流程 |
| `backups/` | 本機備份（不進 Git）：`exe/` 舊版執行檔、`code/` 驗證前程式快照與 `lastgood/`、`saves/` 存檔測試副本、`archive/` 雜項；遊戲快照在 `game-bundles/<版本>/`。桌面版執行時的存檔備份在執行檔旁 `backups/{softcore,hardcore,snapshots}/` |
| `tests/live-harness/`、`docs/`、`game-bundles/` | 跨模組的實機測試、文件、遊戲快照 |
