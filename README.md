# D2倖存者工具包

《D2 Survivors》（d2survivors.lol）的非官方存檔修改器，介面支援繁體中文與英文（依系統語言自動切換）。物品直接使用遊戲本身的產生器製作，數值範圍與遊戲一致。

- **網頁版（電腦／手機）**：<https://nojackno2-ctrl.github.io/d2-survivors-toolkit/>
- **Windows 桌面版**：到 [Releases](https://github.com/nojackno2-ctrl/d2-survivors-toolkit/releases) 下載 `D2.exe`（可攜版，免安裝）
- **介紹網頁**：<https://d2-survivors-toolkit.nojackno2.workers.dev>

> ⚠️ 修改前請先備份存檔。本工具與遊戲官方無關，使用風險自負。

## 功能

| 頁面 | 說明 |
|---|---|
| 物品 | 瀏覽角色、傭兵、倉庫、背包、護身符欄的物品；編輯底材、品質、屬性，複製或移動物品；顯示每個屬性的遊戲範圍 |
| 製作裝備 | 自選底材、品質與屬性訂製裝備；魔法／稀有分成「前綴」「後綴」「固有屬性」三區，選好底材與品質就顯示各區已用／上限；列出底材可用的詞綴範圍，新增屬性預設最大值；名稱依遊戲詞綴規則決定 |
| 裝備庫 | 從遊戲全部暗金、套裝、符文之語中挑選製作，可一次製作多件、取最高數值（暗金、套裝、符文之語需解除修改限制） |
| 帳號 / 強化 | 金幣、光之碎片、傭兵欄；恰西永久強化與額外強化（未解除限制時單次升級花費不超過 100 億）；各角色技能修改、重置次數、恐怖區域 |
| 反修改偵測 | 合規檢查：依遊戲本身的規則（金幣上限、物品合法性、稀有物品 +技能、屬性點上限、角色等級、簽章、匯入痕跡等）掃描存檔，標出會被排行榜拒絕的項目 |
| 存檔管理 | 快照備份、還原、建立全新存檔 |
| 原始 JSON | 直接檢視與編輯存檔內容 |
| 設定 | 介面語言（自動依系統語言切換繁體中文／English）；「解除修改限制」：預設關閉，依原版規則限制數值與裝備屬性 |

## 語言功能與遊戲中文化

桌面版可執行 `node lang/tools/desktop-lang.mjs` 注入語言模組；安裝於系統目錄時需要系統管理員權限，遊戲更新後須重新執行。使用 `node tools/desktop-lang.mjs --restore` 還原備份。語言選單中的「使用 D2R 原版字型…」可從本機《暗黑破壞神 II：獄火重生》擷取字型。

載入修改器後，遊戲暫停時（#paused 可見或選單開啟）畫面**中間上方**會出現「🌐 語言」按鈕：
- **切換語言**：點擊展開下拉選單，可即時切換遊戲語言（預設為「繁體中文」`zh-TW`，亦可切換回原文「English」`en`）。選擇會自動保存在 `localStorage["d2lang"]`。
- **全面 DOM 翻譯**：透過 `MutationObserver` 監看遊戲畫面，翻譯包含浮動文字、HUD Banner、UI 按鈕標籤、`placeholder`、`title`、`aria-label` 等，並支援數字樣板（例如 `# seconds left` → `剩餘{0}秒`）。切換至 `en` 時利用 `WeakMap` 原文快取精確還原。
- **翻譯範圍**：使用遊戲原生的翻譯器（遊戲韓文版用的同一套比對規則）查我們的字典；除 DOM 外也翻譯畫在 Canvas 上的文字。遊戲及網頁／桌面修改器共用 `zh-TW.json`；舊版 `locales/zh-TW.json` 僅保留作歷史資料，不再載入。以遊戲 20261101.1 全部 11826 條介面字串比對，繁中全部有譯文（DPS、Discord 保留原文）。切換語言後，已畫在 Canvas 上的文字要等畫面重畫才會更新。
- **遊戲更新後補字**：執行 `node lang/tools/lang-missing.mjs zh-TW 缺漏.json` 會下載遊戲目前的字串清單與翻譯器（會在本機執行遊戲的翻譯器程式碼），列出翻不到的英文，翻好後補進 `zh-TW.json`，並同步桌面來源。遊戲中也可在主控台執行 `__d2lang.missing()` 查看畫面上出現過但沒翻到的文字。
- **即時切換語言**：繁中與 English 雙向即時切換，不重新整理頁面、網頁版也不必再點書籤；遊戲文字畫布都記下原文，切換時以新語言原地重畫。
- **物品名稱**：魔法物品依「字尾＋字首＋底材」、兩個字的稀有名稱依兩字分別翻譯。
- **工具聯動**：切換為英文時，輔助器（autobot）介面與修改器（editor）亦會同步切換為英文顯示；切換為繁體中文時全面恢復繁中。
- **如何擴充新語言**：
  1. 在 `lang/locales/` 目錄新增語言字典檔（例如 `lang/locales/ja.json`，格式與 `zh-TW.json` 相同：英文原文 → 譯文，數字位置寫 `#`，譯文以 `{0}`、`{1}` 代回）。可先用 `node lang/tools/lang-missing.mjs ja ja-待翻.json` 產生全部待翻字串。
  2. 在 `lang/lang.js` 的 `LOCALES` 清單常數中加入該語言代碼與名稱，例如：
     ```js
     { code: "ja", name: "日本語", file: "locales/ja.json" },
     ```
  3. 亦可在執行階段透過 `window.__d2lang.register(code, { name, dict })` 動態註冊新語言。

未解除修改限制時，修改器依原版規則限制可製作內容：不能製作暗金、套裝、符文之語；魔法最多 1 前綴＋1 後綴，稀有 2～6 個詞綴（前後綴各最多 3 個、稀有珠寶最多 4 個、同類不重複，依 Diablo II 原版規則）；稀有物品最多一條職業／技能樹 +技能（遊戲 10/20 起的規則）；屬性點不超過等級應得上限；屬性下拉選單只列出依規則還能加入的屬性；金幣不超過 100 億；恰西升級單次花費不超過 100 億。這些限制不代表排行榜會接受成績。

> ⚠️ **單機模式：排行榜上傳強制關閉。** 工具包定位為單機爽玩：載入工具包後，排行榜上傳一律強制關閉，遊戲選項中也無法再打開，正在等待上傳的排行榜紀錄也會一併刪除；修改器寫入的存檔同樣關閉上傳。想上排行榜，請關閉已載入工具的分頁，另開乾淨的新分頁直接進入原版遊戲頁面，全程不要載入任何書籤工具。

開啟「解除修改限制」就是單機爽玩模式：製作裝備不設任何限制（任何屬性、任何數量、超過原版數值、所有品質），讓玩家盡情製作超強裝備。不論此開關，載入工具包後排行榜上傳一律關閉。

屬性範圍來自統一的資料庫：暗金、套裝、符文之語取遊戲產生器的上下限；魔法、稀有等其他品質取底材可用詞綴的範圍。

## 遊戲輔助器

載入修改器後，遊戲暫停時左上角會出現「輔助」按鈕，可開啟設定面板；自動戰鬥運作中畫面下方有「停止自動戰鬥」按鈕，下方顯示輔助器目前在做什麼。只操作原版的輸入與流程，不改角色數值或任務旗標。

| 分頁 | 功能 |
|---|---|
| 戰鬥輔助 | 自動喝水（含預判致命傷害，靠近魔王時提早補血）；自動走位：偵測地圖上的怪物、看小怪合計威脅（打不痛、能秒殺的不閃）、預判包圍提前往空隙走、重擊飛彈與精英近戰左右橫移閃避、依技能攻擊距離決定站位；自動撿裝（全圖撿取，沒用的賣掉、有用的穿上或存倉庫）、全圖吸經驗；死亡保護（快被打死時以原版「儲存並離開」回營地，再自動繼續） |
| 自動戰鬥 | 三種自動模式（見下）；升級一定選卡（依排行榜高手配法，技能進化後可再次習得基礎技能）；屬性點依排行榜比例分配；換裝讓每個欄位都有裝備、優先排行榜推薦的暗金／套裝；護符依屬性挑選；讀法典並套用技能變體；使用任務獎品；回營地先交任務再整備（收藏、存倉庫、賣裝、買生命藥水、恰西升級與買裝備）；技能配置和排行榜差太多時向阿卡拉付費重置技能 |

**自動模式**

| 模式 | 內容 |
|---|---|
| 任務模式 | 完成所有任務並練到 99 級：檢測目前任務狀態（例如「尋找凱恩」進行到哪一步），撿到卷軸回營地請阿卡拉翻譯、觸碰石塊陣、進傳送門救出凱恩，回營地向阿卡拉／凱恩交任務；打完巴爾先回營地整備再開最高難度；75 級以上不回普通、85 級以上不回惡夢刷。普通、惡夢、地獄 18 項任務完成且 99 級後，自動改成固定關卡模式刷地獄 |
| 固定關卡模式 | 重複刷指定難度（普通／惡夢／地獄） |
| 天梯模式 | 推關（恐怖層數往上推）或固定層數（重刷指定層，須已通關） |

- 「自動戰鬥」開著就包含戰鬥輔助（走位、閃避、喝水、撿物）；只開「戰鬥輔助」則只幫忙戰鬥、不自動推進。
- 遊戲重新整理或重新開啟後點書籤，兩個總開關預設關閉；同一頁面內重新點書籤則沿用原本的開關。其他設定會儲存沿用。
- 戰鬥中按「停止自動戰鬥」只會關閉自動戰鬥；設定面板的「立即停止輔助」會關閉兩個開關；死亡保護、錯誤停機等自動停機不會改掉你存的設定。
- 畫面上方狀態列顯示目前模式與輔助器正在做什麼；設定面板顯示任務進度。目前模式用不到的設定會自動隱藏。
- 遊戲版本更新後，輔助器與修改器的設定上方會提示「遊戲已更新」，代表尚未驗證新版，部分功能可能失效。
- 不保證存活或通關；遊戲機制分析見 [docs/game-analysis](docs/game-analysis/README.md)。

**實測數據**

- 全新存檔的法師全自動打通普通（第五幕 82 級擊敗巴爾）與惡夢，推進到地獄第二幕；在地獄陣亡後自動回惡夢練等。
- 以 35 個存檔長時間實戰，依結果修正精英判斷、閃避、換裝、配點、交任務等數十項行為；營地整備實測可自動賣裝、買穿皮甲並升級生命。
- 選卡、配點、技能變體與換裝參考排行榜各職業前 50 位玩家的實際配置。

**自動戰鬥並不完美**

- 不保證存活或通關：實測曾在惡夢撿物時被頭目一擊打掉 900 血、藥水用完時走進毒魔群陣亡；地獄難度仍常陣亡。
- 最高難度連續失敗 3 次會自動回低一級刷，進度可能比手動慢。
- 讀法典、使用任務獎品、交伊尼弗斯卷軸、石陣鑰匙等流程尚未完整實測，可能需要手動處理。
- 建議偶爾查看狀況，長時間無人看管前請先備份存檔。

## 網頁版使用方式（書籤教學）

網頁版是一個「書籤小程式」：在遊戲頁面上點書籤後，遊戲暫停畫面的右上角會多出「修改器」按鈕，點它就會在遊戲上方開啟修改器。

### 步驟 1：取得書籤程式碼

打開[安裝頁](https://nojackno2-ctrl.github.io/d2-survivors-toolkit/)，按「📋 複製書籤程式碼」。程式碼長這樣（以安裝頁複製的為準）：

```text
javascript:import('https://nojackno2-ctrl.github.io/d2-survivors-toolkit/d2edit.js?v='+Date.now())
```

### 步驟 2：加入書籤

**電腦（Chrome／Edge／Firefox）**
1. 按 `Ctrl+Shift+B` 顯示書籤列。
2. 把安裝頁上的「D2 修改器」連結直接拖到書籤列，即完成。
3. 或：在書籤列按右鍵 →「新增網頁」，名稱填 `D2 修改器`，網址貼上程式碼，儲存。

**Android（Chrome）**
1. 隨便把一個網頁加入書籤（例如安裝頁，點右上「⋮」→ ☆）。
2. 「⋮」→「書籤」→ 找到剛剛的書籤 → 編輯。
3. 名稱改成 `D2 修改器`，網址**整個刪掉**後貼上程式碼，儲存。

**iPhone／iPad（Safari）**
1. 按分享 →「加入書籤」，儲存。
2. 打開書籤清單 →「編輯」→ 點剛剛的書籤。
3. 名稱改成 `D2 修改器`，網址刪掉貼上程式碼，完成。

> 部分瀏覽器貼上時會自動刪掉開頭的 `javascript:`，請確認網址開頭仍是 `javascript:`。

### 步驟 3：開啟修改器

1. 到 [d2survivors.lol/play](https://d2survivors.lol/play/) 開啟遊戲。
2. 載入書籤（畫面中央會顯示進度條，依序讀取輔助器、字典、遊戲資料、物品引擎與修改器頁面，全部完成才可使用；約 5～10 秒）：
   - **電腦／iPhone**：直接點書籤。
   - **Android**：在**網址列輸入「D2 修改器」**，點下方建議清單出現的書籤（從書籤清單直接點不會執行）。
3. 在遊戲中按**暫停**，畫面**右上角**會出現「修改器」按鈕，點它開啟修改器。
4. 修改後按「寫入存檔」，再按「關閉」，遊戲會重新載入並套用。重新整理頁面後需再點一次書籤。

### 常見問題

- **點了書籤沒看到修改器**：這是正常的，請在遊戲中按暫停，按鈕在右上角。
- **暫停後沒有按鈕**：確認網址開頭是 `javascript:`，且目前在 `d2survivors.lol` 的頁面上；Android 必須從網址列開啟。
- **出現舊版介面**：書籤每次都會載入最新版，重新整理遊戲頁後再點一次即可。
- **需要連網**：第一次開啟需要載入遊戲程式。

網頁版直接讀寫瀏覽器裡的存檔，不經過遊戲的匯入功能，不會留下匯入紀錄。

## 桌面版使用方式

1. 下載 `D2.exe`，可對照 `SHA256SUMS.txt` 確認檔案完整。
2. 關閉遊戲後執行修改器，它會讀取已安裝遊戲的存檔。
3. 修改後按「寫入存檔」，每次寫入前會自動備份。

執行檔未經程式碼簽署，Windows 可能跳出 SmartScreen 警告，請選「其他資訊 → 仍要執行」。

## 注意事項

- 修改套裝、魔法、稀有物品的屬性後，遊戲可能判定為「Not legit」（只影響排行榜），可到「反修改偵測」頁處理。
- 自訂任意屬性不一定有對應的遊戲名稱；無法唯一判定名稱時會提示，不會猜測。
- 「可用詞綴範圍」是此底材可能出現的詞綴，並非都能同時出現。
- 遊戲更新後部分功能可能失效（設定上方會提示），請回報問題；每次遊戲更新，本專案全部功能都會重新驗證。
- 「診斷資訊」會記錄物品引擎各步驟耗時與遊戲版本，回報載入慢或異常時請附上。

## 開發

```bash
# 網頁版：程式與資料都在根目錄對應資料夾（唯一來源），沒有副本。
node tools/build-web.js https://nojackno2-ctrl.github.io/d2-survivors-toolkit/   # 產生安裝頁、轉址頁、version.json

# 桌面版：editor/ 只是啟動器，介面與引擎資源從網站載入；只有啟動器程式改動時才需要重建。
cd editor
npm install
npm start          # 執行桌面版（開發用）
npm run dist       # 封裝 Windows 可攜版（僅 editor/ 改動時需要）
```

| 位置 | 內容 |
|---|---|
| `helper/tests/autobot.cjs` | 輔助器模擬測試（Electron 執行，失敗不中斷，最後列出全部失敗項目） |
| `tests/live-harness/` | 實機長跑測試框架：每職業多個全新存檔，一律以 GitHub 連結（書籤方式）載入，輔助器全自動遊玩 |
| `helper/tools/ladder-learn.js` | 排行榜學習：各職業前 50 位不同玩家，同一玩家只取最高恐懼層紀錄 |
| `docs/game-analysis/` | 遊戲反編譯分析（核心、戰鬥與命中率、物品與掉落、成長與任務、介面、全職業技能），不含遊戲原始碼 |
| `AI_HANDOFF.md` | 交接紀錄、長期規則與所有 AI 代理文件（單一檔案） |
