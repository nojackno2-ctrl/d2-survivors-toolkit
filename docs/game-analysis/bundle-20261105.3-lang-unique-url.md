## 語言與插值

**已從程式碼確認：**原生只有 `en`、`ko`。語言優先讀取 `localStorage` 的 `d2s:lang`，僅接受這兩值；否則從瀏覽器語言選韓文或英文。切換會保存並重新載入。韓文初始化動態載入 `ko` 字典及字型，建立翻譯器並翻譯頁面；英文沒有建立該韓文翻譯器時回傳原文。韓文字型優先載入 `../fonts-ko/` 的 `kodia.woff2`、`irisl.woff2`，失敗時使用 Galmuri。

**已從程式碼確認：**字典鍵以英文原文為基礎，查找前合併空白、去除首尾空白並轉大寫。分類精確鍵為 `kind:原文`，例如 `item:`、`affix:`、`title:`；找不到分類鍵會退回一般翻譯。一般物品走 `item`，`rare` 保留原名；`magic` 在有底材時拆出字首、字尾及底材，依字尾、字首、底材順序翻譯。

**已從程式碼確認：**鍵中的 `#` 表示從輸入擷取數字段落，譯文以 `{0}`、`{1}` 等零起算索引帶入；數字可含小數點或逗號。`*` 表示擷取任意片段，譯文同樣用 `{n}`，且片段會遞迴嘗試翻譯；固定部分至少須有三個英文字母，較長固定部分優先。一般樣板不跨 ` · ` 清單片段，除非樣板本身包含該分隔符。未完整翻譯的萬用比對可作後備；另有換行、標點、` · `、` / `、` - `、冒號與數值前後綴的分段處理，遞迴深度受限。找不到時保留原文並記錄缺漏。

**相容性，已從程式碼確認：**目前 `lang/lang.js` 動態尋找 `translate-*.js` 的匯出類別，依原型上的 `translate`、`translateAs` 識別，並以自己的字典建立實例；本版 `t` 符合這些介面，也具備掛接時使用的 `translateMagic`、`find` 與 `exact`。原生韓文時包裝三個翻譯方法；另行擴充 `find` 的清單與物品名稱組合。載入或掛接失敗時有簡易翻譯／DOM、Canvas 後備。這是介面靜態相容，並非所有字典詞條、繪製路徑或實際翻譯結果均已驗證。

## 收藏分類與資料

**已從程式碼確認：**分類依序為 `head`、`amulet`、`body`、`shield`、`gloves`、`belt`、`boots`、`ring`、`axe`、`sword`、`mace`、`scepter`、`dagger`、`throwing`、`javelin`、`spear`、`polearm`、`bow`、`crossbow`、`staff`、`wand`、`orb`、`claw`、`charm`、`runeword`；未知分類追加，空分類不顯示。暗金與套裝從資料提供者取得，分類用 `kind ?? type`，分別加上 `rarity: unique`／`set`；符文之語歸入 `runeword`。各分類為 `{id, label, uniques}`，按名稱排序時忽略開頭 `The `。

**已從程式碼確認：**收藏內容是 `save.uniques` 物品陣列，定義檢查限 `unique`、`set`、`runeword`。一般物品以 `name` 找定義且檢查 `rarity`、`base`；符文之語名稱鍵為 `runeword:${name}`，收藏識別另接正規化底材，因此同一符文之語可收藏不同底材。加入會刪除位置 `at`，重複識別鍵回傳 `taken`；移除使用陣列中的物件身分。符文之語底材統計以可用底材數及現有數計算，總數取兩者較大值；另有 `全部定義數 + 符文之語定義數 × 4` 的預估值，不能當作實際合法底材總數。

**已從程式碼確認：**比較較佳物品時依序檢查 `forge.up`、打包後的 `forge`、各 `stats` 的 `stat`／`param` 加總、技能 `level`、特定索引數值與 `defense`；批次處理按收藏識別鍵挑選較佳候選。修改器 `unlock` 會產生物品，刪除 `at` 後加入 `save.uniques`；其符文之語重新產生也保留 `name` 和 `base`。**推測：**修改器若只以名稱判重，可能漏掉同名不同底材的合法收藏；此處未完整稽核修改器所有判重流程，亦未實機驗證讀檔。

## 資源網址

**已從程式碼確認：**模組在初始化時，非 `choice` 指定的特殊環境下，嘗試解析頁面元素 `#d2-files` 的 JSON；失敗則使用空資料。資料讀取 `webp`、`recolors` 集合及 `hashes`，其中雜湊以傳入路徑最後一個 `/` 之前的目錄為鍵。`t(path, suffix = "", {png = false} = {})` 以 `../d2/` 為前綴：若該目錄有雜湊，回傳路徑加 `?h=<hash>`，忽略 `suffix`；若偵測支援 WebP、該目錄在 `webp` 集合、路徑以 `.png` 結尾且未要求 `png`，副檔名改為 `.webp`。無雜湊時保留原路徑並直接附加 `suffix`，不做 WebP 替換。`n(url)` 僅檢查 `searchParams` 是否含 `h`，不驗證其值或來源；`i(path)` 僅檢查 `recolors` 的精確集合成員。WebP 支援以 1 像素資料圖片的 `decode()` 結果判定，未完成偵測前預設不替換。

**推測：**`h` 用於資源快取版本區分；這五個檔案未證明伺服器的快取政策或參數驗證方式。
