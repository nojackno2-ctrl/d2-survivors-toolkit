D2倖存者工具包

《D2 Survivors》（d2survivors.lol）非官方工具包：存檔修改器 × 遊戲輔助器 × 繁體中文化

修改器用遊戲自己的物品產生器做裝備，數值範圍和遊戲完全一致；還能依遊戲自己的規則掃描存檔，列出問題位置與修正方式。
輔助器只走遊戲原本的操作流程，幫你喝水、閃避、撿寶，並一路推任務與天梯。
中文化即時翻譯介面與物品名稱，譯名對齊原版《暗黑破壞神 II》官方繁體中文。
不用安裝：電腦或手機瀏覽器加一個書籤就能用，也有免安裝的 Windows 可攜版。

安裝教學

安裝教學

網頁版是書籤小程式（Bookmarklet），電腦與手機瀏覽器皆免安裝；Windows 另有可攜版

注意：單機模式：載入工具包後排行榜上傳強制關閉、無法打開，詳見 已知問題。

01

取得書籤程式碼

前往網頁版安裝頁，按「複製書籤程式碼」。內容如下（以安裝頁複製的為準）：

javascript:import('https://nojackno2-ctrl.github.io/d2-survivors-toolkit/d2edit.js?v='+Date.now())
02

加入瀏覽器書籤

依裝置操作方式不同，見下方三種平台說明。部分瀏覽器貼上時會自動刪掉開頭的 javascript:，請確認網址開頭仍是它。

03

在遊戲頁點書籤

到 d2survivors.lol/play 點書籤，畫面中央的進度條會同時載入字典、遊戲資料、語言模組、輔助器、自動淬鍊、物品引擎與修改器頁面，並做相容性自檢（約 5～10 秒）。接著按暫停，點左上角的「工具包」，選單依序是：輔助器、自動淬鍊、掛機、中文化、修改器、效能（自動淬鍊與掛機需先進入遊戲選好職業）。

電腦（Chrome／Edge／Firefox）

  1. 按 Ctrl+Shift+B 顯示書籤列。
  2. 把安裝頁上的「D2 修改器」連結直接拖到書籤列。
  3. 或在書籤列按右鍵 →「新增網頁」，網址貼上程式碼。

Android（Chrome）

  1. 隨便把一個網頁加入書籤（「⋮」→ ☆）。
  2. 「⋮」→「書籤」→ 編輯剛剛的書籤。
  3. 名稱改為 D2 修改器，網址整個刪掉後貼上程式碼。
  4. 使用時：在網址列輸入「D2 修改器」，點建議清單中的書籤（從書籤清單直接點不會執行）。

iPhone／iPad（Safari）

  1. 按分享 →「加入書籤」並儲存。
  2. 打開書籤清單 →「編輯」→ 點剛剛的書籤。
  3. 名稱改為 D2 修改器，網址刪掉後貼上程式碼。
  4. 使用時：在遊戲頁直接點書籤。

Windows 桌面版

  1. 到 Releases 下載 D2.exe（可攜版，免安裝），可對照 SHA256SUMS.txt 確認檔案完整。
  2. 關閉遊戲後執行，會讀取已安裝遊戲的存檔。
  3. 修改後按「寫入存檔」，每次寫入前自動備份。

執行檔未經程式碼簽署，若出現 SmartScreen 警告請選「其他資訊 → 仍要執行」。

存檔修改器

存檔修改器：9 個分頁詳解

暫停時點左上角的「工具包」，再選「修改器」開啟；修改後按「寫入存檔」再「關閉」，遊戲會重新載入並套用

01

物品

瀏覽並編輯存檔裡所有位置的物品，點選即可看到完整屬性與遊戲數值範圍。

  • 所有位置：共用倉庫 1～3；各職業的身上裝備（含備用武器組）、個人倉庫、背包、咒符欄、傭兵裝備。
  • 其他：鑰匙與器官（首領掉落）、獨特收藏、賣出紀錄（可買回）。
  • 獨特收藏：「一鍵解鎖＋全部最高」補齊收藏庫，數量與遊戲一致；地獄火炬的職業技能依目前職業給予。
  • 符文之語：可勾選是否無形。
  • 可編輯：底材、品質與每一條屬性數值；也可複製或移動物品。
  • 數值範圍：每條屬性旁顯示遊戲正常範圍。
02

製作裝備

自選底材、品質與屬性訂製裝備，未解除限制時一律照原版規則。

  • 魔法／稀有：逐步選單——依序選裝備類型、品質、（武器的）武器種類、底材，每一步選完才出現下一步，只列出有底材的選項；「前綴」「後綴」「固有屬性」分區顯示已用／上限，新增屬性預設帶入最大合法值。
  • 獨特／套裝／符文之語：挑選物品後可在原版範圍內調整數值與原版本來就隨機的項目（如地獄火炬職業、是否無形）；符文之語只列原版允許的底材。
  • 放到：只能選共用倉庫 1～3、目前角色的個人倉庫與背包（一般製作與批次製作都適用）。
  • 未解除修改限制：也能製作獨特、套裝與符文之語，屬性種類與數量固定為原版定義。
  • 複合詞綴：可唯一判定就自動補入配套屬性；有多種可能時提示確認，不猜測。
  • 孔數與珠寶：可設定孔數並鑲嵌。
  • 輸出裝備設定：一鍵複製表單內容供回報問題，不含存檔資料。

詞綴上限：魔法 1 前綴＋1 後綴；稀有 2～6 個（前後綴各最多 3）；稀有珠寶最多 4。

03

裝備庫

從遊戲全部獨特、套裝、符文之語，以及稀有／魔法底材中挑選並直接製作。

  • 用遊戲自己的產生器：做出來的物品與遊戲掉落完全相同（含可驗證的種子）。
  • 數值：可選隨機、最高，或「自訂（限原版範圍）」。
  • 批次製作：可一次製作多件（未解除限制時最多 40 件）。
  • 搜尋：中英文名稱皆可搜尋，依品質與類型篩選。
04

帳號 / 強化

調整帳號資源與各角色的成長設定。

  • 基本：金幣、光之碎片、可聘傭兵欄（遊戲只接受 1、2、3、5）。
  • 恰西強化：永久強化等級與額外強化，可一鍵全部設定。
  • 角色：各職業解鎖難度、金色光芒、技能改造點數、已付費重置次數、開放的恐怖等級。
  • 技能修改：照遊戲規則每職業最多 10 點，每點替一個技能選一種修改。

未解除限制時：金幣不超過 100 億、額外強化不超過 999。

05

存檔檢查

依遊戲本身的檢查規則掃描整份存檔，列出問題位置、原因與修正方式。

  • 問題明細：逐項標出位置（職業、背包、倉庫分頁、裝備欄位、傭兵、商店等）與怎麼修正。
  • 偵測項目：金幣上限、光之碎片、物品合法性、角色等級、簽章、標記與匯入痕跡；可一鍵全部規避。
  • 遊戲診斷：顯示遊戲此刻看到的頁面狀態，也可貼上遊戲的診斷訊息，標出與排行榜有關的欄位。
  • 存檔識別碼：可重新產生排行榜與角色識別碼（會重設爬塔與恐懼紀錄，寫入後生效）。

合法性以遊戲自己的資料與檢查為準，正常打到的裝備不會被判為不合法。載入工具包後排行榜上傳一律關閉（單機模式），見已知問題。

06

存檔管理

修改前的安全網。

  • 快照：自訂名稱建立快照，在「備份與快照」清單隨時載入或刪除。
  • 自動備份：網頁版與桌面版寫入存檔前都會自動備份原存檔。
  • 匯出／匯入：存檔可匯出成檔案或從檔案匯入；修改器直接寫入，不留下遊戲的匯入紀錄。
  • 建立全新存檔：以遊戲空白存檔為基礎，只帶入勾選的內容，識別碼與紀錄由遊戲重新產生。
07

原始存檔資料

直接以 JSON 檢視與編輯存檔內容，按「套用」後才生效；適合熟悉資料結構的玩家，修改前請先建立快照。

08

設定

修改器的全域選項。

  • 解除修改限制預設關閉：關閉時照原版規則把關；開啟後可設數值倍率、製作數量不限，做出超出原版範圍的裝備（見合規原則）。
  • 診斷資訊：產生並複製修改器狀態與最近操作紀錄，回報問題時附上；不含識別碼。
09

更新日誌

修改器內也能查看每天的更新內容，與本頁更新日誌相同。

遊戲輔助器

遊戲輔助器

暫停時點左上角的「工具包」，再選「輔助器」開啟設定面板；戰鬥輔助與自動戰鬥只使用原版輸入與流程，「遊戲修改」另可變更遊戲數值

兩個總開關的關係

兩個總開關各自獨立：「戰鬥輔助」負責喝水、走位、閃避、撿寶與死亡保護；「自動戰鬥」負責開局、選卡、配點、換裝與推進關卡，不會順便開啟戰鬥輔助。想全自動掛機請兩個都開。

重新整理遊戲或重新開啟後再點書籤，兩個總開關與「遊戲修改總開關」一律預設關閉，避免一進遊戲就自動操作；同一頁面內重新點書籤則沿用原狀態。其他細部設定會儲存沿用。手動操作時輔助器會暫時讓出控制權；背景分頁、設定面板、修改器開啟或遊戲暫停時也會停止動作。

你自己決定要打哪裡，輔助器負責保命與撿東西。

生命與藥水

  • 自動喝生命藥水：低於設定的生命門檻（％）就喝。
  • 一擊必殺預判：預估接下來幾秒（可設定）的傷害會致命時提早喝水。
  • 魔王附近：600 範圍內有幕末魔王或頭目時，喝水門檻提高到 80％。
  • 可設定藥水冷卻毫秒數，以及無法掛接遊戲時使用的藥帶欄（1～4）。

走位與閃避

  • 合計威脅：打不痛、能秒殺的小怪不閃，避免越閃越遠。
  • 預判包圍：以 16 個方向取樣，提前往空隙移動。
  • 重擊閃避：單發傷害大的飛彈往彈道橫向閃開；精英／頭目近戰時橫向繞圈。
  • 戰鬥方式：自動（依已學技能射程）、近戰貼身、遠程保持距離三選一。

撿寶

  • 自動撿寶：依遊戲內建的撿寶過濾器決定保留、隱藏或自動販售，請在遊戲設定調整過濾器。
  • 全圖撿寶預設開啟：撿取距離改為全圖，要撿哪些依遊戲過濾器；撿回來沒用的由營地整備賣掉換金幣。
  • 全圖吸經驗非原版行為：地上經驗寶石自動飛來。
  • 全圖吸金幣預設關閉：獨立開關，關閉時保留原版撿取。
  • 踢罐子木桶：可能掉藥水；附近有敵人時不去。
  • 通關後等待撿裝：地上還有想要的裝備時先撿完再進傳送門；有寶箱時最多等 20 秒。

死亡保護 預設開啟

  • 預估接下來的傷害會致命且沒有可用的回血藥水，或生命低於緊急門檻（預設 15％）且藥水冷卻中時觸發。
  • 觸發後以原版「暫停 → 離開本局」離場回營地，避免陣亡從 1 級重來；回營地後自動戰鬥會接著繼續。
  • 可選擇「觸發後關閉兩頁總開關」，離場後就停下來等你處理。
  • 離場也算一次失敗，計入「連續失敗回低一級」的次數。

判定為啟發式，不保證生存。

開啟「自動戰鬥開關」並選擇自動模式，輔助器會自己開局、選卡、配點、換裝、回營地整備。目前模式用不到的設定會自動隱藏。

MODE 01 // QUEST

任務模式

目標是完成所有任務並練到 99 級。讀取存檔判斷目前任務進度與「尋找凱恩」的步驟，優先接近任務頭目。

撿到卷軸→ 回營地找阿卡拉翻譯→ 觸碰石塊陣→ 進傳送門救凱恩→ 回營地交任務
  • 打完巴爾先回營地整備，再開最高已開放難度。
  • 75 級以上不回普通、85 級以上不回惡夢刷。
  • 普通、惡夢、地獄共 18 項任務完成且達 99 級後，自動改為固定關卡模式刷地獄。
MODE 02 // FARMING

固定關卡模式

選擇普通、惡夢或地獄，重複刷同一難度：自動開局、清圖、撿寶、回營地整備，適合穩定累積金幣與裝備。

MODE 03 // LADDER

天梯模式

兩種方式：

  • 推關：恐怖層數一層一層往上推。
  • 固定層數：重刷指定層數，該層須已通關。
  • 可設定通關後等待秒數，以及有保留角色時陣亡後重試。

各模式共用的自動行為

依排行榜高手配法

  • 選升級卡：優先進化卡，其次依排行榜技能與被動權重；技能進化後可再次習得基礎技能。
  • 自動重抽：候選卡評分偏低時使用重抽。
  • 自動配點：依該職業高手的屬性比例逐點分配。
  • 重置技能：技能配置與排行榜差太多時向阿卡拉付費重置（普通通關後可用），重置後立刻重新選卡。

資料取自排行榜各職業前 50 位不同玩家，遊戲改版後重新抓取。

自動換裝

  • 以遊戲原版數值比較裝備，替換門檻約等於傷害提升％。
  • 每個欄位都會補上裝備；優先排行榜高手常用的獨特／套裝。
  • 同時計分生命、減傷與四系抗性，避免換成玻璃大砲。
  • 自動讀赫拉迪克法典並套用技能變體、使用任務獎品。

回營地整備

  • 先交任務：每次回營地先向凱恩／阿卡拉回報已完成的任務。
  • 獨特／套裝收進收藏庫，較好的裝備存倉庫。
  • 賣掉用不到的裝備（符文、寶石、咒符、任務物品不賣）。
  • 向阿卡拉買生命藥水、向恰西升級永久能力與買裝備。

難度調整

  • 最高難度連續失敗 3 次，會回低一級刷一局。
  • 某難度完整打完卻整局沒升級，之後該等級以上不再回去刷。
  • 在營地自動開局或續玩，全新存檔也能直接開始。

單機娛樂用的數值修改，全部預設關閉，並由「遊戲修改總開關」統一控制。這些修改會改變遊戲數值，不屬於原版行為。

遊戲修改總開關

  • 遊戲修改總開關預設關閉：主控所有修改項目；預設關閉。

戰鬥修改

  • 無敵：免疫所有傷害且鎖定滿血。
  • 致命攻擊：致命一擊機率最高。
  • 一擊必殺：所有屬性傷害提升一百倍。
  • 所有技能 +20：提高裝備「+所有技能」屬性，不改技能等級。

怪物與環境修改

  • 怪物數量最大化：怪物數量最大化。
  • 一般怪物全部變成精英以上等級：一般怪物全部變成精英以上等級。

流程與掉落修改

  • 燃燒的恐懼精華數量 99：以虛擬精華提供，不放實體物品，淬鍊時自動補足。
  • 淬鍊與地獄熔爐本地化：不連伺服器，本機直接算出結果，不受限流；機率同原版。
  • 本地淬鍊必定成功、地獄熔爐必定倍增：需開啟本地化；自動淬鍊只會淬到你設定的目標屬性。

自動淬鍊

自動淬鍊

進入遊戲後隨時開啟自動淬鍊面板，支援逐件與多件並行淬鍊、屬性目標設定與本地化快速淬鍊

開啟方式

進入遊戲後，暫停點「工具包」→「自動淬鍊」，不必走到恰西的鐵砧；面板可收合成小圖示；視窗最小化後仍會持續淬鍊。

可淬鍊的裝備

依原版規則——普通、稀有、套裝、獨特與符文之語可以淬鍊，魔法品質以及咒符等類型不行；用過地獄熔爐（不論成功或失敗）的裝備不再列出。來源可選角色背包或個人倉庫。

屬性目標

替每條屬性設定目標；設為 X 的屬性表示不要淬到。同一款裝備的目標會記住，下次自動帶入。面板會顯示精確計算的機率與約需清除次數；被選為目標的屬性連續 200 次成功淬鍊都未升級時會跳出警告。

序列

「加入同名」一鍵把同名同底材的裝備全部加入序列；「同時淬鍊 N 件」（1～10，預設 1）；「同款熔爐成功就略過其餘同款」（預設開啟）；「失敗就自動售出」可把熔爐失敗的裝備賣掉（倉庫裡的也可以）。

伺服器限流

官方伺服器依網路 IP 對淬鍊限流（約每小時 1200 次）。被限流時會依伺服器告知的時間等滿後接著做同一件；伺服器沒說要等多久時，每次等 1 分鐘、最多重試 3 次後換下一件。收合成圖示時會顯示等待倒數，結束時顯示成功與失敗件數。

本地化淬鍊

在輔助器「遊戲修改」分頁開啟，需同時開啟遊戲修改總開關。「淬鍊與地獄熔爐本地化」讓淬鍊、清除、地獄熔爐由本機直接算出結果，不連官方伺服器，所以不會被限流，機率與原版相同，照樣消耗精華；「本地淬鍊必定成功、地獄熔爐必定倍增」需搭配本地化，自動淬鍊只會淬到設定為目標的屬性。

精華

每次淬鍊消耗燃燒的恐懼精華；可在「遊戲修改」開啟「燃燒的恐懼精華數量 99」。

注意

本機淬鍊的結果官方伺服器並不知道。之後若停用工具包，或關掉本地化後再對同一件裝備淬鍊，該裝備的淬鍊可能被伺服器的舊紀錄蓋回去。

掛機與效能

選好職業後可按右上角懸浮的「掛機」，以黑幕蓋住整個畫面，遊戲、輔助器與自動淬鍊照常執行，點畫面即喚醒；工具包選單也有此功能。「效能」頁顯示更新率、記憶體等即時數據，並有「掛機時略過主畫面繪製」開關（預設開啟，實測掛機時處理器與顯示卡負擔約減少四成）。

已知問題

已知問題

單機模式：排行榜上傳強制關閉

工具包定位為單機爽玩：載入工具包後，排行榜上傳一律強制關閉，遊戲選項中也無法再打開，正在等待上傳的排行榜紀錄也會一併刪除；修改器寫入的存檔同樣關閉上傳。想上排行榜，請關閉已載入工具的分頁，另開乾淨的新分頁直接進入原版遊戲頁面，全程不要載入任何書籤工具。

手機：暫停選單點擊可能沒有反應

部分手機在遊戲暫停時點選選單沒有反應。原因尚未確認，目前無法在真實手機上重現。遇到時請回報手機型號與瀏覽器，方便追查。

輔助器：任務模式地獄第四幕任務預設略過

地獄「擊殺巴爾」任務要求巴爾受傷時單一技能樹傷害占 75% 以上，傭兵與裝備傷害也算在分母，實測有機率失敗。任務模式預設略過這項、不再等待；想挑戰可開啟「失敗後重置技能」，成功率仍不保證。其餘三難度的任務在 10 個實例的實測中，8 個全數完成。

輔助器：長時間掛機仍建議先備份

任務模式已從普通一幕連續打到地獄做過 10 實例長時間測試，全程無死亡；自動推關的完整長時間流程仍未完整驗證。長時間掛機前建議先在「存檔管理」建立快照。

手機：遊戲介面右上狀態跳動、停止按鈕遮擋

部分手機直向畫面中，右上角狀態可能跳動並遮住遊戲時間，「停止自動戰鬥」按鈕也可能遮住腰帶。原因與修正仍在查，尚未完成手機驗證。

繁中字型：少數字可能顯示異常

德魯伊部分技能說明中的「藤」「擊」「技」「喚」等字，在遊戲字型中是否會缺字尚未確認，若遇到顯示成方框或異常，請回報截圖。

常見問題

常見問題

點了書籤卻沒看到修改器？

這是正常的。暫停時點左上角的「工具包」，再選「修改器」或「輔助器」，請先在遊戲中按暫停。

暫停後還是沒有按鈕？

確認書籤網址開頭是 javascript:，且目前位於 d2survivors.lol 的頁面。Android 必須從網址列輸入書籤名稱開啟，從書籤清單點選不會執行。第一次開啟需要連網載入遊戲程式。

看到舊版介面怎麼辦？

書籤每次都會載入最新版。重新整理遊戲頁後再點一次書籤即可；重新整理後本來就需要再點一次。

改完存檔後要怎麼套用？

按「寫入存檔」，再按「關閉」，遊戲會重新載入並套用。網頁版直接讀寫瀏覽器裡的存檔，不經過遊戲的匯入功能，不會留下匯入紀錄。

獨特、套裝或符文之語為什麼不能加屬性、調超過範圍？

預設照原版規則：可以製作，但屬性種類與數量固定為原版定義，數值只能在原版範圍內調整。想自由改，請在修改器「設定」開啟「解除修改限制」。

製作裝備時提示「可能配套」或要我確認？

部分詞綴會同時帶多條屬性。修改器只在能唯一確定是哪個詞綴時才自動補入配套屬性；同一屬性也可能來自單獨詞綴時，會標示「可能配套」並請你確認，不會猜測。若結果與預期不同，可按「輸出裝備設定」複製診斷內容回報。

遊戲更新後還能用嗎？

版本不同時不會封鎖使用，但修改器與輔助器上方會提示「遊戲已更新」，表示尚未驗證新版，部分功能可能失效。發現問題請到 GitHub 回報。

關閉遊戲修改後，數值會還原嗎？

會。關閉各項開關會還原無敵、致命攻擊、一擊必殺、掉寶率、金幣、經驗值與怪物數量；只有已經變成精英的怪物會維持原狀。

可以放著輔助器長時間掛機嗎？

可以，但不保證存活或通關，地獄難度仍常陣亡。建議偶爾查看狀況，長時間無人看管前請先在「存檔管理」建立快照。
