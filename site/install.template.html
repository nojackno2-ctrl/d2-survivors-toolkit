D2倖存者工具包（網頁版）

給在瀏覽器（電腦或手機）玩 d2survivors.lol（官方遊戲）的玩家。用書籤在遊戲頁面上載入工具包（輔助器、自動淬鍊、中文化、修改器、存檔檢查與防護）。修改器專門修改單機存檔（線上存檔僅供檢視）；輔助器在記憶體中運作，未來線上存檔仍可用。

排行榜上傳強制關閉

載入工具包後，單機與線上存檔的排行榜上傳一律強制關閉，遊戲選項中也無法再打開，正在等待上傳的排行榜紀錄也會一併刪除。可在「存檔檢查與防護」查看狀態。

遊戲目前只有單機存檔；線上存檔是未來規劃，修改器偵測到線上存檔時僅供檢視、不寫入。

1. 複製書籤程式碼

電腦：也可以直接把這個按鈕拖到書籤列 → D2 修改器

2. 加入書籤

電腦（Chrome／Edge／Firefox）

  1. 按 Ctrl+Shift+B 顯示書籤列，把上面的「D2 修改器」按鈕拖到書籤列即可。
  2. 或在書籤列按右鍵 →「新增網頁」，名稱填 D2 修改器，網址貼上程式碼，儲存。

Android（Chrome）

  1. 隨便把一個網頁加入書籤（例如這一頁）。
  2. 到「書籤」找到它 → 編輯。名稱改成 D2 修改器，網址整個刪掉，貼上剛剛複製的程式碼，儲存。

iPhone（Safari）

  1. 按分享 → 加入書籤，儲存。
  2. 打開書籤 → 編輯 → 點剛剛那個書籤。名稱改成 D2 修改器，網址刪掉貼上程式碼，完成。

部分瀏覽器貼上時會刪掉開頭的 javascript:，請確認網址開頭仍是 javascript:。

3. 使用

  1. 打開 d2survivors.lol/play。
  2. 載入書籤：Android 在網址列輸入「D2 修改器」，點下面出現的書籤（從書籤清單點不會執行）；iPhone／電腦 直接點書籤。畫面不會變化，遊戲照常進行。
  3. 在遊戲中按暫停，畫面左上角會出現「工具包」按鈕，點開選單有：輔助器、自動淬鍊、掛機、中文化、修改器、存檔檢查與防護、效能。
  4. 選「修改器」開啟存檔修改器。
  5. 單機存檔改完按「寫入存檔」，再按「關閉」，遊戲會重新載入並套用（線上存檔僅供檢視）。重新整理頁面後需再點一次書籤。

修改前建議先到「存檔管理」按「建立快照」，會下載一份備份檔。物品引擎直接使用遊戲本身的程式產生物品，第一次開啟需要連網。修改器預設依原版規則限制數值與裝備屬性，可在「設定」解除（後果自負）。
