D2倖存者工具包（網頁版）

給在瀏覽器（電腦或手機）玩 d2survivors.lol 的玩家。用書籤在遊戲頁面上開啟修改器，直接讀寫瀏覽器裡的存檔，不經過遊戲的匯入功能，不會留下匯入紀錄。 English

單機模式：排行榜上傳強制關閉

工具包定位為單機爽玩：載入工具包後，排行榜上傳一律強制關閉，遊戲選項中也無法再打開，正在等待上傳的排行榜紀錄也會一併刪除；修改器寫入的存檔同樣關閉上傳。想上排行榜，請關閉已載入工具的分頁，另開乾淨的新分頁直接進入原版遊戲頁面，全程不要載入任何書籤工具。

1. 複製書籤程式碼

電腦：也可以直接把這個按鈕拖到書籤列 → D2 修改器

2. 加入書籤

電腦（Chrome／Edge／Firefox）

  1. 按 Ctrl+Shift+B 顯示書籤列，把上面的「D2 修改器」按鈕拖到書籤列即可。
  2. 或在書籤列按右鍵 →「新增網頁」，名稱填 D2 修改器，網址貼上程式碼，儲存。

Android（Chrome）

  1. 隨便把一個網頁加入書籤（例如這一頁）。
  2. 到「書籤」找到它 → 編輯。名稱改成 D2 修改器，網址整個刪掉，貼上剛剛複製的程式碼，儲存。

iPhone（Safari）

  1. 按分享 → 加入書籤，儲存。
  2. 打開書籤 → 編輯 → 點剛剛那個書籤。名稱改成 D2 修改器，網址刪掉貼上程式碼，完成。

部分瀏覽器貼上時會刪掉開頭的 javascript:，請確認網址開頭仍是 javascript:。

3. 使用

  1. 打開 d2survivors.lol/play。
  2. 載入書籤：Android 在網址列輸入「D2 修改器」，點下面出現的書籤（從書籤清單點不會執行）；iPhone／電腦 直接點書籤。畫面不會變化，遊戲照常進行。
  3. 在遊戲中按暫停，畫面右上角會出現「修改器」按鈕，點它開啟修改器。
  4. 改完按「寫入存檔」，再按「關閉」，遊戲會重新載入並套用。重新整理頁面後需再點一次書籤。

修改前建議先到「存檔管理」按「建立快照」，會下載一份備份檔。物品引擎直接使用遊戲本身的程式產生物品，第一次開啟需要連網。修改器預設依原版規則限制數值與裝備屬性，可在「設定」解除（後果自負）。

D2 Survivors Toolkit (web)

For players of d2survivors.lol in a browser (desktop or mobile). A bookmark opens the editor on top of the game page and reads/writes the save stored in your browser directly — no in-game import, so no import record is left. 繁體中文

Known issue: leaderboard scores may not upload

Some players report that scores may not upload after loading a toolkit bookmark, even without editing a save. The cause is unconfirmed.

Temporary workaround: Close the game tab where a toolkit was loaded, open a clean new tab directly to the original game page, and do not load D2 Toolkit or other bookmark tools during that session. This cannot guarantee that the game will accept a score.

1. Copy the bookmarklet

Desktop: you can also drag this button to the bookmarks bar → D2 Editor

2. Add the bookmark

Desktop (Chrome / Edge / Firefox)

  1. Press Ctrl+Shift+B to show the bookmarks bar and drag the "D2 Editor" button onto it.
  2. Or right-click the bookmarks bar → "Add page", name it D2 Editor, paste the code as the URL and save.

Android (Chrome)

  1. Bookmark any page (for example this one).
  2. Open "Bookmarks", find it → Edit. Rename it to D2 Editor, delete the whole URL, paste the code and save.

iPhone (Safari)

  1. Tap Share → Add Bookmark, save.
  2. Open Bookmarks → Edit → tap that bookmark. Rename it to D2 Editor, replace the URL with the code, done.

Some browsers strip the leading javascript: when pasting — make sure the URL still starts with javascript:.

3. Use it

  1. Open d2survivors.lol/play.
  2. Load the bookmark: on Android type "D2 Editor" in the address bar and tap the bookmark suggestion (tapping it in the bookmark list won't run it); on iPhone / desktop just tap it. Nothing changes on screen and the game keeps running.
  3. Pause the game — an "Editor" button appears in the top-right corner. Tap it to open the editor.
  4. When done press "Write save", then "Close"; the game reloads with your changes. After a page reload, tap the bookmark again.

Tip: create a snapshot on the Saves page first — it downloads a backup file. The item engine uses the game's own code, so the first launch needs an internet connection. By default the editor keeps values and gear within the original game rules; you can remove this in Settings at your own risk.
